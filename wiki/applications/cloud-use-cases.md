# 雲端運算實際應用（Cloud Use Cases）

## 1. 資源擴充

來源依據：[CC-002](../sources/CC-002_Google_Cloud_Computing.md)；NIST 情境分析：[CC-004](../sources/CC-004_NIST_SP_800-146.md)。
Google Cloud 說明，當企業遇到流量或業務需求變動時，雲端服務可依需求調整運算資源，避免長期持有過多閒置設備。（CC-002）

## 2. 資料儲存與備份
雲端儲存可用於保存大量資料、提高資料可存取性及支援備份。Google Cloud 將資料儲存及災難復原列為常見應用情境。（CC-002）

## 3. 應用程式開發與測試
雲端平台可提供開發、部署及測試應用程式所需的工具與環境，減少等待採購及配置實體基礎設施的時間。（CC-002、CC-005）

## 4. 大數據分析
Google Cloud 將大數據分析列為雲端使用情境，雲端資源可用於處理大量資料，支援研究及分析工作。（CC-002）

## 5. 混合雲與備援
NIST SP 800-146 描述混合雲情境，例如在平常使用私有雲處理工作負載，需求高峰時再使用外部雲端資源（cloud bursting）；也可使用另一雲端提供備份或災難復原資源。

## 6. 應用情境選擇提醒
雲端是否適合某項工作，仍需考量資料敏感性、網路依賴、效能、可靠性、法規、成本及退出／移轉方式，不能只以「雲端較便宜」作為判斷。
