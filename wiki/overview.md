# Cloud Computing Overview

## 主題介紹
雲端運算讓使用者透過網路，依需求取得共享且可配置的運算資源。NIST SP 800-145 提供核心定義、五項基本特徵、三種服務模式及四種部署模式；其他來源則補充架構、服務判斷、技術優缺點與安全責任。

## 六大知識章節
1. **基本概念**：雲端運算定義、五項特徵、效益及限制。
2. **服務模式**：SaaS、PaaS、IaaS，以及服務分類與評估。
3. **部署模式**：Private、Community、Public、Hybrid Cloud。
4. **運作技術**：參考架構角色、服務協調、資源抽象與控制、硬體資源及虛擬化。
5. **資料與安全**：供應商與使用者責任、資料治理、隱私、存取控制及安全風險。
6. **實際應用**：資源擴充、資料儲存、備份復原、應用程式開發及資料分析。

## 來源定位
- **NIST 文件**：作為定義、參考架構、服務分類及評估方法的主要依據。
- **Google Cloud 文件**：作為入門解說、雲端架構元件及 Google Cloud 安全責任觀點的補充。Google Cloud 文件屬供應商觀點，不取代 NIST 的中立分類。

## 重要界線與待注意事項
- NIST SP 800-145 定義四種部署模式；Google Cloud 入門文章以公有、私有及混合雲作為該文介紹的三種模式。Wiki 的正式分類仍保留 NIST 四種。
- Google Cloud Shared Fate 是 Google 對其雲端安全合作方式的描述，不應寫成所有雲端供應商共同採用的通用標準。
- NIST SP 800-146 為 2012 年文件，適合作為技術與風險分析基礎；涉及當前產品功能或最新法規時，仍需查閱現行文件。
