# Cloud Computing Wiki

## 專案介紹
本 Wiki 以雲端運算（Cloud Computing）為主題，從正式定義與基本分類出發，整理雲端架構、服務評估、安全責任及實際應用。內容以 NIST 官方出版品作為標準與架構基礎，並以 Google Cloud 官方教學文件補充入門說明及供應商觀點。
