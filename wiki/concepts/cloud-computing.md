# 雲端運算基本概念（Cloud Computing）

## 1. 雲端運算定義

來源依據：[CC-001](../sources/CC-001_NIST_SP_800-145.md)；入門補充：[CC-002](../sources/CC-002_Google_Cloud_Computing.md)。
NIST SP 800-145 將雲端運算定義為一種模式，使使用者能透過網路，方便且依需求存取共享的可配置運算資源池；資源可以快速提供及釋放，且只需要少量管理工作或服務供應商互動。資源例子包括網路、伺服器、儲存空間、應用程式及服務。（CC-001，文件印刷頁碼第 2 頁）

Google Cloud 的入門文章則以較簡明的方式說明：雲端運算是透過網際網路，以服務形式依需求取得運算資源，例如儲存空間及基礎設施；使用者不必自行管理實體資源，並依使用量付費。（CC-002，網頁「Cloud computing defined」）

## 2. 五項基本特徵

來源依據：[CC-001](../sources/CC-001_NIST_SP_800-145.md)；評估角度補充：[CC-006](../sources/CC-006_NIST_SP_500-322.md)，第 3 節。
1. **隨需自助服務（On-demand self-service）**：使用者可依需求自行配置運算能力。
2. **廣泛網路存取（Broad network access）**：透過網路及標準機制存取，支援不同用戶端平台。
3. **資源池化（Resource pooling）**：供應商整合資源，以多租戶方式服務使用者，並依需求動態分配。
4. **快速彈性（Rapid elasticity）**：資源可依需求快速增加或釋放。
5. **可衡量的服務（Measured service）**：監控、控制及回報資源使用情況。
來源：CC-001；CC-006 第 3 節進一步分析五項特徵。

## 3. 雲端運作概念
Google Cloud 說明，使用者透過網路連接雲端平台，向遠端伺服器所提供的共享運算、儲存及網路資源提出請求。雲端供應商負責管理其雲端資源，使用者依服務模式取得不同層級的能力。（CC-002）

## 4. 效益與限制

來源依據：[CC-002](../sources/CC-002_Google_Cloud_Computing.md)；NIST 風險及建議：[CC-004](../sources/CC-004_NIST_SP_800-146.md)，第 8、9 節。
### 常見效益
- **彈性與擴充性**：依需求增加或減少資源。
- **降低前期建置負擔**：不必先採購及建置完整實體資料中心。
- **快速部署**：可較快取得運算資源及開發環境。
- **依使用量付費**：可依資源使用方式計費，但仍須評估整體成本。
來源：CC-002；CC-004 Executive Summary。

### 需要評估的限制
- 網路延遲、連線中斷及資料匯入／匯出瓶頸可能影響服務。
- 供應商服務中斷可能影響業務持續性。
- 資料可攜性、供應商互通性及遷移成本需要事先評估。
- 安全、隱私、法規遵循及資料所在地需要納入規劃。
來源：CC-004 第 8 節及第 9 節。
